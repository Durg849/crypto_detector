API Documentation

Integrate Injecto into your AI app in under 5 minutes.

Base URL

https://injecto.xyz

Authentication

Pass your API key in the request header:

x-api-key: inj_your_key_here

Detect Endpoint

POST /api/detect

import requests response = requests.post( "https://injecto.xyz/api/detect", headers={"x-api-key": "inj_your_key_here"}, json={"prompt": "user message here"} ) result = response.json() print(result)

Response Format

{ "safe": true, "risk_score": 10, "severity": "LOW", "attack_types": [], "patterns": [], "prompt_length": 5, "timestamp": "2025-06-20T10:30:00" }

Response Fields

FieldTypeDescription
safebooleanTrue = safe, False = injection detected
risk_scoreinteger0–100 risk score
severitystringLOW / MEDIUM / HIGH
attack_typesarrayTypes of attacks detected
patternsarrayExact patterns that matched

Python Example (Full Integration)

import requests def is_safe(user_message): res = requests.post( "https://injecto.xyz/api/detect", headers={"x-api-key": "inj_your_key"}, json={"prompt": user_message} ) return res.json().get("safe", False) # In your app: user_input = "Hello, how are you?" if is_safe(user_input): # Send to your AI (Claude, GPT, etc.) pass else: print("Blocked: Injection attempt detected")
